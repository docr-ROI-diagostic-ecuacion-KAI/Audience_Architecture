LCP · Largest Contentful Paint

Answers: how quickly does the main content become visible? It measures when the largest relevant element in the initial viewport is rendered. A slow LCP often points to heavy hero images, slow server response or render-blocking resources.

Good ≤ 2.5 s
INP · Interaction to Next Paint

Answers: how quickly does the page react when the user clicks, taps or types? It evaluates responsiveness across real interactions. A high INP usually means the browser main thread is too busy with JavaScript or long tasks.

Good ≤ 200 ms
CLS · Cumulative Layout Shift

Answers: does the interface stay visually stable while it loads? It detects unexpected movement of text, buttons, images or banners. Stable dimensions for media, fonts and dynamic components help keep CLS low.

Good ≤ 0.10
DOC ROI CWV Score

A simple 0–100 teaching synthesis calculated from the Core Web Vitals that are actually available. It helps students scan the overall situation quickly; it is not an official Core Web Vital and does not replace the three individual metrics.
