LCP · Largest Contentful Paint

Answers: how quickly does the main content become visible? It measures when the largest relevant element in the initial viewport is rendered. A slow LCP often points to heavy hero images, slow server response or render-blocking resources.

Good ≤ 2.5 s
INP · Interaction to Next Paint

Answers: how quickly does the page react when the user clicks, taps or types? It evaluates responsiveness across real interactions. A high INP usually means the browser main thread is too busy with JavaScript or long tasks.

Good ≤ 200 ms
CLS · Cumulative Layout Shift

Answers: does the interface stay visually stable while it loads? It detects unexpected movement of text, buttons, images or banners. Stable dimensions for media, fonts and dynamic components help keep CLS low.

Good ≤ 0.10
DOC ROI CWV Score

A simple 0–100 teaching synthesis calculated from the Core Web Vitals that are actually available. It helps students scan the overall situation quickly; it is not an official Core Web Vital and does not replace the three individual metrics.

Marketing Planning & Market Activation · Deliverables Center
The primary output is the Marketing Plan. It connects objectives, POSE, System → Medium → Support → Format, audience, proposition, investment, KPI, UTM / TAG evidence, the operational capacity gate and the downstream DOC ROI handoffs.

  

    
PRIMARY DELIVERABLE
DOC ROI · Marketing Plan
The decision document that explains what Marketing will activate, why it is justified, how much is committed, which KPI proves success, whether Operations can absorb the demand and which downstream system receives the next evidence.

    

      
CONTENT PRODUCTION
Media Content House Handoff
Turns approved plan actions into producible briefs without losing audience, proposition, POSE or channel context.
  • Audience + proposition + 4P
  • Medium · Support · Format
  • CTA · UTM · tags · creative prompt

      
DEMAND GENERATION
MQL Activation Handoff
Defines the evidence a marketing interaction must create before it can become a workable marketing-qualified lead.
  • Campaign / UTM lineage
  • Expected behaviour + trigger
  • Consent requirement

      
COMMERCIAL PRODUCTIVITY
SQL Handoff Contract
Prepares the commercial context required by Sales. It does not invent SQLs, pipeline stages or WON / LOST evidence that has not yet happened.
  • Qualification reason
  • Value proposition + evidence
  • Status: awaiting real MQL / SQL data

      
CUSTOMER EXPERIENCE
CX Activation Handoff
Preserves the marketing promise and combines it with SPO / NPS signals so post-conversion experience can prioritise recovery, protection or development.
  • Customer + NPS + 4P
  • Promise / service risk
  • Recommended action

      
CUSTOMER PORTFOLIO
Loyalty Handoff
Exports the customer-level intelligence already present in SPO for retention, membership, referral and next-best-value decisions.
  • SPO · RFM · NPS · ABCD
  • Preferred 4P
  • Recommended channel / action

      
PRODUCT EXPERIENCE
Product Experience Handoff
Passes campaign acquisition lineage into the Information Cascade and conversion layer without inventing later customer behaviour.
  • source · medium · campaign
  • entry 4P · UTM · tags
  • landing destination

      
SEARCH ACTIVATION
SEM Keyword Plan
Keeps the paid-search decision separate from the SEO backlog and preserves intent, match type and strategic tag evidence.
